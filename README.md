# Lee primero los dos documentos de referencia y revisa el código existente del proyecto antes de...

Lee primero los dos documentos de referencia y revisa el código existente del proyecto antes de hacer cambios. No reinventes funcionalidades ni APIs que ya existen; si la documentación contradice al código, prioriza siempre el código real.

A partir de lo definido en los documentos, implementa el frontend de CRUCE respetando la arquitectura, stack, APIs, componentes y restricciones existentes. Mantén la navegación definida para usuario: Inicio, Intercambios, Colección, Sobres y Perfil.

Aplica también el sistema visual definido: dark mode, minimalista, profesional, premium y tecnológico, con naranja como color principal. La estética de coleccionables tipo TCG debe aparecer principalmente en la experiencia de abrir sobres y revelar stickers, sin convertir toda la aplicación en un videojuego.

Antes de implementar, identifica qué ya está construido y qué falta, y trabaja sobre ello sin duplicar funcionalidades.
